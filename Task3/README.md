# Оценка Data Encryption at Rest and In Transit

## Классификация данных

### По состоянию
- at rest (данные в базах данных, данные в excel документах, сканы на файловой системе)
- in transit (данные во время передачи из системы в систему)
- in use (данные во время использования, например при автоматическом анализе или статистика)
### По профилю риска 
- Высокий риск (конфиденциальные данные пациентов, мед карты пациентов, платежные данные)
- Средний риск (нормативные документы клиники, фин отчеты клиники, бухгалтерия)
- Низкий риск (складская информация клиники, инвентаризация)

## Использовать автоматизированный контроль
- SIEM‑системы (Security Information and Event Management): например, ELK. Логи будут храниться в Elasticsearch, а в кибане возможно настроить дашборды для мониторинга и автоматической нотификации в случае необходимости. 
- Data Loss Prevention подход, например: Microsoft Purview DLP, Symantec DLP
- RBAC для раздачи минимально необходимых прав доступа к данным
- SSO для защиты от несанкционированного доступа к данным 
- Data Catalog & Tagging для фильтрации и контроля данных. Например, Apache Atlas, Collibra.
